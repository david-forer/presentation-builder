# HTML Deck Generator – Plan

## Goal
Turn notes into a single self-contained HTML presentation in under 30 seconds.

## Core Flow
1. User pastes notes
2. User sets slide count and theme
3. App calls AI
4. App shows preview
5. App lets user download index.html

## Non-Goals
- No user accounts
- No saved projects
- No multi-file exports
- No team features
- No design editor

## Success Criteria
- HTML opens locally by double click
- Keyboard navigation works
- Slides look visually strong without manual tweaking
- Total codebase stays under ~500 lines
